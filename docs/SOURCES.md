# 精选点播来源与验证记录

> 2026-10-16 更新：「精选点播」已从 4 个扩充至 21 个 HTTP 来源，另有「综合片库」合并网站来源。当前完整列表与逐源解码结果见 [本轮扩充说明](SOURCE-EXPANSION.md)。以下保留 2026-10-12 的初次检查记录，暂未纳入的结论也仅适用于当时。

检查日期：2026-10-12，中国标准时间。本次测试在项目当前 macOS 网络及内置浏览器上执行。

在侧边 TVBox 配置下拉框选择「精选点播」。它包含 4 个 HTTP JSON 点播源，沿用现有搜索、线路、选集和 HLS 播放流程，不需要 Android 模拟器、账户、数据库或新服务。Windows 也走相同 HTTP 播放路径，不依赖仅在 macOS 可用的 Python 插件隔离。

配置文件随项目发布；内置入口直接读取本机 `configs/selected.json`，不用先访问 GitHub 下载配置。影片数据与媒体仍需联网。「电视」仍是原默认配置。

3840×1608 是视频实际解码尺寸，不能仅凭它保证原生拍摄分辨率、码率或所有影片均为 4K。光速样本的 HLS 主列表标注 1920×1080，但实际视频只有 1280×720；因此以上表格优先采用浏览器 `videoWidth / videoHeight`。其余影片需要逐片判断，不能把站名或 HD 标签视为质量保证。

魔都电影样本含画面内嵌的推广字幕和水印，播放器不能直接去除。这些来源是可用性与分辨率筛选，不是对无广告片源的保证。

四个源的分类、首页列表、搜索、详情、线路与选集均经过检查。还抽样查询《流浪地球2》《斗罗大陆》，验证 HLS 播放列表与首个媒体分片可读取。魔都没有返回《庆余年第二季》的同名样本，但《庆余年第一季》及电影样本可读取；同名《斗罗大陆》含动漫和电视剧，检查时需要核对类型与年份。

## 后续手动检查

```bash
npm run probe:sources
# 或指定样本标题
npm run probe:sources -- "庆余年第二季" "流浪地球2"
```

命令只在主动执行时访问网络，不在启动或 CI 时运行。每条输出包含日期、来源、影片、类型、线路、集数、播放列表声明的分辨率和分片请求结果。名称完全匹配且多个版本存在时优先取动漫版本；它是抽样诊断，不能替代浏览器实播或完整影片检查。

命令只读少量媒体分片后取消连接，不保存影片文件，不安装依赖。任何样本缺失或媒体检查失败时退出码为 1；某源未收录指定片名也会触发该退出码，应结合逐条输出判断。
