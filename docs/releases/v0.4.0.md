My TV 首个完整桌面发行版

- 提供 macOS 与 Windows 原生图形启动器，可点击启动、停止和打开观影网页。
- 启动器显示当前版本，支持检查更新、查看更新说明和打开版本下载页。
- 默认「全部」聚合各配置，兼容片源去重，搜索结果按来源区分。
- 支持观看历史、跨源续播、首页继续观看，以及历史搜索和清空。
- 修复图形启动器未沿用系统代理导致部分封面无法加载的问题，封面暂时失败可自动重试。
- 服务关闭后释放端口，保留本地观看历史；支持可选局域网共享。

使用前需自行安装 Node.js 22.18+ 与 Python 3.11–3.14。项目依赖由启动器检查并补齐。Mac 支持 Intel / Apple Silicon；Windows 使用系统 .NET Framework。
