# 综合片库与本次片源扩充

验证日期：2026-10-16，中国标准时间。

侧边 TVBox 配置选择「综合片库」，一次搜索 **21 个 HTTP 点播源 + 3 个网站片源，共 24 个来源**。本轮新增 17 个 HTTP 来源；「精选点播」提供同一批 HTTP 来源，「网页精选」提供已有的 HDmoli、A123TV、金牌影视。默认配置仍为「电视」。

分类页显示当前一个来源的片库，可点击「换个片库」切换；搜索采用现有的滚动并发队列，有结果即展示，并保留来源筛选。不同来源、年份、版本的搜索条目分别显示，不把同名电影、电视剧、动漫混成同一入口。

## 采用的方案

参考 MoonTV / LibreTV 的通用点播接口方案，复用本项目已有的 HTTP JSON、搜索、详情、选集与 HLS / MP4 代理。相比引入整套采集框架或常驻浏览器，公开接口能以较小改动扩充来源，也适用于 Windows、macOS。不增加运行依赖、数据库或中间件。

两个配置快照均随代码发布，内置入口读取本机文件，不依赖先下载 GitHub 配置。综合片库保存完整的公开配置，方便查看和导出；回归测试检查它与两个子配置一致，避免维护中漏加来源。新增来源保留独立且稳定的 key。

不少接口同时返回网页线路与媒体线路。内置 HTTP 精选启用 My TV 的 `directOnly: true`，只呈现具有实际 m3u8 / MP4 等地址的选集；不按集数补造缺集，也不把网页播放器当作视频。这不适用于所有扩展名缺失的流媒体接口，因此没有强制应用到外部自定义配置。

已有的同源、SSRF / DNS、TLS、媒体 MIME 与跨域凭证限制继续生效，不关闭证书验证，不执行候选仓库中的脚本。网站需要访问验证、登录或浏览器嗅探时，本轮不通过绕过这些限制来扩充数量。

以上只表示本次环境中的观测，不代表站点永久失效。对于搜索关闭的接口，没有改用规避限制的方式请求。

## 手动复查与维护

```sh
# 检查内置 HTTP 来源（可指定影片名）
npm run probe:sources -- 流浪地球2

# 对自备的候选 JSON 做受限并发抽样，不修改内置菜单
npm run probe:candidates -- candidates.json results.json 流浪地球2 仙逆
```

候选文件采用 `{"sites":[{"key":"demo","name":"片源","type":1,"api":"https://example.com/api.php/provide/vod"}]}` 格式。工具最多接受 100 个候选，4 个任务并发，设有请求及单来源截止时间；只读取少量分片后取消，不下载完整影片，不在启动或 CI 自动联网扫描。结果中的媒体检查表示小范围可读性，不代替独立解码或浏览器实播。
