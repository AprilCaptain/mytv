# 网页精选与网站适配器

验证日期：2026-10-16（中国标准时间）。侧边配置选择「网页精选」，即可从 HDmoli、A123TV、金牌影视浏览、搜索与播放。原「电视」「精选点播」「橘子柚」继续保留。

也可选择「综合片库」，将这 3 个网站与 21 个 HTTP 来源一起搜索。见 [片源扩充说明](SOURCE-EXPANSION.md)。

## 实现方式

网站适配器在 Node 服务中执行项目内置代码，只读取公开页面中的分类、影片、选集、播放器 JSON 与必要的公开播放请求，不导入远程脚本到 Node，不使用 Android、OmniBox / DRPY 宿主、常驻 Chromium 或新中间件。没有增加 npm / Python 依赖。

HDmoli 适配分类、分页、搜索、详情与选集；读取其公开播放器的数据请求，使用 Node 内置 crypto 处理播放地址的 URL 包装。这是地址格式兼容，不是破解媒体 DRM。网盘 / 下载入口不加入播放线路。A123TV 适配公开页面与 `pp` JSON 数据；按当前电影的实际媒体地址去重，最多保留 6 个候选线路，读取各线路自己的选集名称，不按数量虚构缺失集数。

金牌影视适配其网页客户端的匿名 API，使用网页公开的请求格式与签名参数，不需要账号。播放接口会列出带登录限制的高清档位，即使返回地址，也一律排除；只选择明确标记为访客可用的最高档位。因此主要补充片库覆盖，不作为 4K / 高清来源。电影、电视剧、动漫、综艺、短剧可浏览，不接入体育直播。

网页媒体会在返回播放器前做短时、小范围可读性检查，连接失败的线路通过原有流程回退；不保证完整影片没有中断。影视媒体仍由现有带签名的代理转发，播放时重新解析地址；历史只记录网站、影片、稳定线路 key、集名与进度，不保存临时媒体凭证。线路改名、排序变化时优先用 key 恢复；电影同一线路的多个画质版本优先恢复原版本名。

不知道完整片库数量时，页面只显示来源，不把当前页条目数当成整个片库数量。电影的多个播放条目显示为「版本」，剧集继续显示「选集」。

## 实际抽样

- HDmoli《人生交换》（2026 日韩剧）：搜索、详情、2 集选集、MP4 与 Range 通过；浏览器实际解码 **1280×720**，时间持续前进。
- HDmoli《哪吒之魔童降世》（2019 剧情片）：线路 1 的 HLS、媒体分片与浏览器实播通过，播放超过一分钟；浏览器得到 **1920×804**，独立解码抽样为 **1920×800**，具体尺寸可能随自适应流或上游变化。服务重启后可从保存的线路、时间续播。
- HDmoli《冰之城墙第二季》（2026 日韩动漫）：搜索、详情、MP4 可读取，未据此推断实际清晰度。
- A123TV《流浪地球 2》（2023 科幻片）：搜索可区分 2023 / 2025 条目，选取 2023 年版本；HLS / 首个媒体分片与浏览器实播通过。浏览器及独立解码检查均得到 **1920×804**，为宽画幅；网站该线路标注 720p，因此不使用站点标签作为实测尺寸。
- A123TV《仙逆》（2023 国产动漫）：多个线路分别保留自己的集数，抽样首集播放列表与媒体分片通过。一个样本的列表标注 1080×608，不能保证所有集数都是高清。
- A123TV《藏海传》（2025 国产剧）：40 集样本线路及 HLS 分片可读取；不同线路的集数并不相同，不补造缺集。
- 金牌影视《流浪地球2》《藏海传》《仙逆》：匿名搜索、详情、HLS 和媒体分片通过，后两者分别取得 40 / 162 集。前两部访客视频独立解码为 **864×364 / 864×360**，属于较低画质，适合作为缺片时的补充。

这些是指定时间、指定影片 / 线路的抽样，不是整站清晰度、覆盖范围或长期可用性的保证。新增网页片源与原有 API 源可能指向相同的上游媒体，不按来源数量推断新增独占影片数量；新增来源也不代表所有影片都达到 4K。

## 安全边界

所有请求沿用公网地址、DNS / 代理连接固定 IP、重定向检查和超时限制。影片 / 播放页 ID 必须属于配置中的网站，额外播放服务地址由适配器固定；不会因页面给出脚本、任意 iframe 或验证码就自动执行或处理。跨域播放服务不接收来源 Cookie / Authorization。

部分 CDN 把 TS / 加密分片标为 PNG / JPEG。媒体代理将这类类型改为 `application/octet-stream`；对于能识别出连续 MPEG-TS 同步包的 PNG / JPEG 前缀，以流方式移除包装并取消失效的长度 / Range 头，其余字节不改写。保留 nosniff 与禁止脚本的内容策略；SVG、HTML、JS 仍拦截。海报入口继续检查真实文件头，未放宽海报规则。详见 [安全说明](../SECURITY.md)。

网站页面只用于提取影片数据，站内广告、页面脚本、播放器广告组件不会嵌入 My TV。网站若引入登录、验证码或新的播放格式，适配可能需要更新，当前不会尝试绕过这些限制。

## 手动复查

```sh
npm run probe:websites
npm run probe:websites -- --source=A123TV 藏海传
npm run probe:websites -- --source=HDmoli 人生交换
npm run probe:websites -- --source=金牌影视 藏海传
```

命令只在主动运行时联网，不在启动或 CI 自动扫描。HLS 检查播放列表与少量分片后取消，MP4 检查响应和大小；不下载整部影片，不把临时播放 URL 打印到结果中。抽样检查不能代替浏览器实播，未收录查询影片也会显示样本缺失。

新增适配器需要项目代码与测试，远程配置只能选择注册的 `adapter`，不能提供可执行代码。自定义兼容站点示例：

```json
{"sites":[{"key":"site","name":"网站名称","type":1,"api":"https://example.com","adapter":"a123tv","searchable":1}]}
```

示例只有在站点页面和播放协议确实兼容时才有效。`adapter` 是 My TV 扩展字段，不能把本配置当作通用 TVBox / OK影视配置直接使用。
